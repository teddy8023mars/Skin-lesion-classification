# ISIC 2018 dataset

The dataset is **not redistributed in this repository**. You must download it
yourself from the official ISIC 2018 challenge page:

**https://challenge.isic-archive.com/data/#2018**

Both notebooks were written for Google Colab and read the data from Google
Drive at `/content/drive/MyDrive/ISIC2018/`. After downloading, unpack the
archives into your Drive using the layout below (or edit the paths in the
notebooks to match wherever you put the files).

## Notes

- **Why `t12` in the folder names:** ISIC 2018 Tasks 1 (segmentation) and 2
  (attribute detection) share the same input images, so the challenge ships
  them as combined "Task1-2" input archives. Only the ground truth differs
  per task (this project uses the Task 1 masks).
- `Task3_train_test_val/`, `image_cache/`, `t3_train_label.csv`, and
  everything under `Models/` are **outputs** created by the notebooks, not
  part of the official download.
- A few exploratory cells in the task-1 notebook reference older path
  variants (`Dataset/test_images/test_t12/`, `Dataset/Task2-3/train_t3/`,
  `Dataset/val_masks/val_t1_gt/`); the layout above is the one the training
  and evaluation code uses.
- Please review the ISIC challenge's data license/terms of use on the
  download page before using the images.
